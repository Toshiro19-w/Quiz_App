                      2. 4 THANH PHAN TINH DIEM
===============================================================================

2.1. HISTORY SCORE - Diem Lich Su Hoc Tap (Trong so: 40%)
-----------------------------------------------------------

Dua tren khoa hoc da mua (Status = "Paid")

Diem cong:
  - Cung Danh Muc (CategoryId):               +60 diem
  - Cung Giang Vien (OwnerId):                +40 diem
  
Toi da: 100 diem

Vi du:
  Da mua: "SQL Server Co ban" (Category: Database)
  Goi y:  "SQL Server Nang cao" (Category: Database) 
  => HistoryScore = 60 diem
  
  Da mua: Khoa hoc cua "Tran Minh Khoa"
  Goi y:  Khoa hoc khac cua "Tran Minh Khoa"
  => HistoryScore = 40 diem
  
  Da mua: "SQL Co ban" cua "Tran Minh Khoa"
  Goi y:  "SQL Nang cao" cua "Tran Minh Khoa"
  => HistoryScore = 100 diem (60 + 40)


2.2. BEHAVIOR SCORE - Diem Hanh Vi (Trong so: 30%)
---------------------------------------------------

Dua tren gio hang hien tai

Diem cong:
  - Da them vao gio hang:                     +100 diem
  - Chua them:                                0 diem

Toi da: 100 diem

Y nghia: 
  Khoa hoc trong gio hang = Y dinh mua cao
  => Uu tien goi y cao nhat


2.3. POPULARITY SCORE - Diem Pho Bien (Trong so: 25%)
------------------------------------------------------

Dua tren danh gia va luot mua

A. So luong mua (0-40 diem):
    > 100 nguoi:    +40 diem
    > 50 nguoi:     +30 diem
    > 20 nguoi:     +20 diem
    > 0 nguoi:      +10 diem

B. Danh gia trung binh (0-40 diem):
    >= 4.5 sao:     +40 diem
    >= 4.0 sao:     +30 diem
    >= 3.5 sao:     +20 diem
    >= 3.0 sao:     +10 diem

C. So luong reviews (0-20 diem):
    > 50 reviews:   +20 diem
    > 20 reviews:   +15 diem
    > 10 reviews:   +10 diem
    > 0 reviews:    +5 diem

Toi da: 100 diem

Vi du:
  Khoa hoc co:
  - 75 nguoi mua:         +30 diem
  - Rating 4.3 sao:       +30 diem
  - 25 reviews:           +15 diem
  => PopularityScore = 75 diem


2.4. TIME & PRICE SCORE - Diem Thoi Gian (Trong so: 5%)
--------------------------------------------------------

Dua tren ngay tao khoa hoc

Diem co ban:                                  50 diem

Diem cong:
  - Tao trong 7 ngay:                         +50 diem (Tong: 100)
  - Tao trong 30 ngay:                        +30 diem (Tong: 80)
  - Tao lau hon:                              +0 diem (Tong: 50)

Toi da: 100 diem

Y nghia: Uu tien khoa hoc moi


===============================================================================
                        3. CONG THUC TONG DIEM
===============================================================================

TotalScore = (HistoryScore x 0.40) 
           + (BehaviorScore x 0.30) 
           + (PopularityScore x 0.25)
           + (TimePriceScore x 0.05)

Tong trong so: 100% (0.40 + 0.30 + 0.25 + 0.05 = 1.00)


===============================================================================
                        4. VI DU TINH TOAN
===============================================================================

Khoa hoc: "C# Nang cao"

Buoc 1: Tinh tung thanh phan
-----------------------------
HistoryScore     = 60   (cung danh muc voi "C# Co ban")
BehaviorScore    = 100  (da them vao gio hang)
PopularityScore  = 80   (75 mua, 4.3 sao, 25 reviews)
TimePriceScore   = 50   (tao 2 thang truoc)

Buoc 2: Ap dung trong so
-------------------------
HistoryScore     = 60  x 0.40 = 24.0
BehaviorScore    = 100 x 0.30 = 30.0
PopularityScore  = 80  x 0.25 = 20.0
TimePriceScore   = 50  x 0.05 = 2.5

Buoc 3: Tong diem
-----------------
TotalScore = 24.0 + 30.0 + 20.0 + 2.5 = 76.5 diem


===============================================================================
                      5. MUC DO TIN CAY (CONFIDENCE)
===============================================================================

Dua tren TotalScore:

  Score >= 70:   HIGH      (Rat phu hop - uu tien cao)
  Score >= 40:   MEDIUM    (Kha phu hop - can nhac)
  Score < 40:    LOW       (It phu hop - khong uu tien)

Vi du:
  TotalScore = 76.5  =>  Confidence = HIGH

                      9. CAU TRUC DU LIEU

class RecommendedCourse
{
    Course Course                   // Thong tin khoa hoc
    decimal TotalScore              // Diem tong (0-100)
    List<string> ReasonTags         // Danh sach ly do goi y
    string ConfidenceLevel          // High/Medium/Low
}

class CourseScore
{
    decimal HistoryScore            // Diem lich su (0-100)
    decimal BehaviorScore           // Diem hanh vi (0-100)
    decimal PopularityScore         // Diem pho bien (0-100)
    decimal TimePriceScore          // Diem thoi gian (0-100)
    decimal TotalScore              // Diem tong trong so
}

===============================================================================
                      11. LUU Y QUAN TRONG
===============================================================================

1. Neu userId = null (chua dang nhap):
   - HistoryScore = 0
   - BehaviorScore = 0
   - Chi goi y dua tren PopularityScore va TimePriceScore
   => Goi y khoa hoc pho bien va moi nhat

2. Trong so da duoc dieu chinh:
   - Da bo RelevanceScore (UserInterests)
   - Tang History: 35% -> 40%
   - Tang Behavior: 25% -> 30%
   - Tang Popularity: 20% -> 25%
   - Giu nguyen Time/Price: 5%

3. Khoa hoc da mua (Status = "Paid") se khong duoc goi y

4. Chi goi y khoa hoc co IsPublished = true


===============================================================================
                      12. UU DIEM THUAT TOAN
===============================================================================

1. Ca nhan hoa cao

                      13. CACH SU DUNG TRONG CODE
===============================================================================

// 1. Khoi tao service
var context = new LearningPlatformContext();
var service = new CourseRecommendationService(context);

// 2. Lay goi y cho user
int? userId = AuthHelper.CurrentUser?.UserId;
var recommendations = await service.GetRecommendedCoursesAsync(userId, 10);

// 3. Hien thi trong HomeControl
foreach (var recommended in recommendations)
{
    var card = CourseRecommendationHelper
                   .CreateRecommendedCourseCard(recommended);
    carouselRecommended.AddCourseCard(card);
}

// 4. Thong tin chi tiet
foreach (var recommended in recommendations)
{
    Console.WriteLine($"Course: {recommended.Course.Title}");
    Console.WriteLine($"Score: {recommended.TotalScore}");
    Console.WriteLine($"Confidence: {recommended.ConfidenceLevel}");
    Console.WriteLine($"Tags: {string.Join(", ", recommended.ReasonTags)}");
}
